# LiteCMS for Cloudflare

一个跑在 Cloudflare 边缘网络上的轻量级 CMS：**Pages + D1 + R2**，无框架、无依赖、单文件后端。

整个程序打包后只有 13 个文件，部署即用，免费额度内可长期运行。

---

## 功能一览

**前台**

- 首页：精选推荐、最新文章（按发布时间倒序）、分页
- 文章页：正文、上一篇 / 下一篇、相关评论、评论表单
- 分类页 / 标签页 / 归档页 / 搜索结果页
- 独立页面：后台创建，可按需挂载到导航栏
- 右侧边栏：实时时钟、搜索框、文章分类、Tags、文章归档、Ta们说（最新评论）、热点（最多评论文章）、公众号二维码
- 侧边栏模块**无数据时自动隐藏**，空站也不会出现空卡片
- 页脚：友情链接、版权、ICP 备案号、公网安备
- 自定义统计代码（支持百度统计、Google Analytics 等任意脚本）

**后台**（`/wp-admin`）

| 菜单 | 功能 |
|---|---|
| 仪表盘 | 文章 / 评论 / 分类统计，待审评论数，快速入口 |
| 文章 | 新建、编辑、筛选、分页、批量操作、回收站（软删除 / 恢复 / 彻底删除）、设精、改状态 |
| 评论 | 审核（通过 / 待审 / 垃圾）、批量处理|
| 分类 | 增删改查，删除分类时文章自动归入「未分类」 |
| 标签 | 增删改查，保存文章时自动创建并建立多对多关联 |
| 页面 | 新建独立页面、设置路径、勾选「显示在前台导航栏」、拖拽无需排序号 |
| 链接 | 友情链接逐条增删、拖拽排序、批量编辑 |
| 媒体库 | 上传 / 浏览 / 搜索 / 删除 R2 文件，编辑器内直接插入 |
| 修改密码 | 修改当前管理员密码 |
| 设置 | 站点信息、统计代码、备案号、评论策略、提示条、二维码等 |

## 技术栈

| 层次 | 实现 |
|---|---|
| 运行环境 | Cloudflare Pages Functions（Workers Runtime） |
| 数据库 | Cloudflare D1（SQLite 语义） |
| 媒体存储 | Cloudflare R2 对象存储 |
| 会话 | 无状态 HMAC-SHA256 签名 Cookie |
| 密码 | PBKDF2-SHA256，10 万次迭代加盐哈希 |
| 前端 | 原生 HTML / CSS / 少量 vanilla JS，服务端渲染 |

## 安装步骤

### 1. 创建 D1 数据库

```bash
npx wrangler d1 create litecms
```

记下返回的 `database_id`。

### 2. 创建 R2 存储桶

```bash
npx wrangler r2 bucket create litecms-media
```

> R2 需要先在 Cloudflare 控制台开通（有免费额度）。不创建也能用，只是媒体库不可用。

### 3. 在 Cloudflare Pages 绑定资源

控制台 → Workers & Pages → 你的 Pages 项目 → **设置 → 函数 → 绑定**，添加：

| 绑定类型 | 变量名 | 值 |
|---|---|---|
| D1 数据库 | `DB` | 第 1 步创建的 `litecms` |
| R2 存储桶 | `MEDIA` | 第 2 步创建的 `litecms-media` |

再在 **设置 → 环境变量** 添加：

| 变量名 | 说明 |
|---|---|
| `SESSION_SECRET` | **必填**。登录 Cookie 的签名密钥，请使用足够长的随机字符串 |

生成随机密钥：

```bash
openssl rand -base64 32
```

### 4. 上传文件

把本压缩包解压后的内容全部上传到 Pages 项目根目录（或用 Git 推送）：

```
你的项目/
├── _worker.js          # 全部后端逻辑与页面模板
├── _headers            # 静态资源 MIME 与缓存声明
└── assets/
    ├── css/
    │   ├── front.css       # 基础前台样式
    │   ├── theme-blue.css  # blue 主题（前台实际使用）
    │   └── admin.css       # 后台样式
    ├── js/
    │   ├── front.js
    │   ├── theme-blue.js
    │   └── admin.js
    └── img/
        └── banner-default.png
```

> 直接通过控制台拖拽上传也可以：把 `_worker.js`、`_headers`、`assets/` 一起拖进 Pages 的部署目录。

### 5. 访问站点完成安装

打开你的域名，会自动跳转到 `/install`：

1. 页面顶部会检查三项环境：**D1 绑定**、**R2 绑定**、**SESSION_SECRET**
2. 填写站点名称、管理员用户名、密码（至少 6 位）
3. 提交后**自动建表**并写入默认设置

安装完成后访问 `/wp-admin/login` 登录。

> 也可以选择手动建表：把安装页提示的 `schema.sql` 内容保存为文件后执行
> `npx wrangler d1 execute litecms --remote --file=./schema.sql`。不推荐，因为安装表单会自动完成。

## 使用说明

### 写第一篇文章

后台 → **文章** → 「新建文章」，填写标题、正文、分类，状态默认发布，保存即可在前台看到。

正文支持两种写法，可混用：

- **HTML**：`<p>`、`<h2>`、`<ul>`、`<img>`、`<blockquote>`、`<table>` 等
- **纯文本**：从其它编辑器粘贴的文字

### 插入图片 / 文件

编辑器工具栏点击 **🖼 媒体** → 上传文件 → 点击列表中的文件即可插入正文：

- 图片插入 `<img>` 标签
- 其它文件插入下载链接

上传的文件按**内容哈希**存储，地址形如：

```
/wp-uploads/{哈希前2位}/{哈希其余62位}.{后缀}
例：/wp-uploads/b9/4d27b993…cde9.png
```

内容相同、后缀相同的文件只存一份，天然去重。

### 设置菜单说明

| 分组 | 项 | 说明 |
|---|---|---|
| 基本信息 | 站点名称 / 副标题 | 显示在页头与浏览器标题 |
| | 网站统计代码 | 原样插入每个前台页面 `</body>` 之前 |
| | 备案号 / 底部资质信息 | 页脚 ICP 备案 |
| | 公网安备 | 填「粤公网安备44098102441016」即自动生成备案查询链接；留空用默认值 |
| | 列表与分页 | 前台每页文章数（默认 6）、后台每页条数（默认 10） |
| 评论 | 开关（默认开）、审核（默认开）、每页条数（20）、提交间隔（30 秒）、单条最大链接数（3）、字数上限（1000）、单 IP 每日上限（15）、提示语 | 详见页面内说明 |
| 页脚提示条 | 开关（默认开）、类型（信息 / 警告 / 危险）、文案 | 关闭后提示条区域不占位 |
| 图片 | 页头横幅、公众号二维码地址与标题 | 支持完整 URL 或 `/wp-uploads/...` |
| 友情链接 | 批量编辑 | 一行一个，格式 `名称 | 地址`，也可只写地址 |

### 独立页面

后台 → **页面** → 新建：

- **路径（slug）** 留空会自动生成；路径不能与系统路由冲突（如 `about`、`search`、`wp-admin` 等），冲突时会自动改名
- 勾选 **「显示在前台导航栏」** 后，页面出现在前台导航（网站首页之后、关于之前）
- 状态为「草稿」的页面，前台不可访问

前台导航顺序：**网站首页 → 自定义页面（按排序值） → 关于**。分类不占用导航位。

### 友情链接排序

后台 → **链接**，按住每行**行首的 ☰ 手柄**上下拖动，松手自动保存。

也可以用键盘：点击手柄使其聚焦后，按 **↑ / ↓** 调整位置并保存。

### 回收站

文章删除后先进入**回收站**，可恢复或彻底删除：

- 后台 → 文章 → 顶部「回收站」标签
- 彻底删除后不可恢复

## 常见问题

**样式没生效 / 页面错乱**

静态资源带有 `?v=版本号` 缓存穿透参数，每次升级会自动更新。若仍异常，请强制刷新（Ctrl/Cmd + Shift + R）。

**提示「未绑定 D1 数据库」**

检查 Pages 项目的绑定里是否有变量名 `DB` 的 D1 数据库绑定，改完需要**重新部署**才生效。

**登录后被立刻弹回登录页**

`SESSION_SECRET` 未配置或部署后发生了变化。配置一个固定的随机值并重新部署。

**媒体库上传失败「未绑定 R2」**

绑定变量名必须是 `MEDIA`，且值为 R2 存储桶。绑定后需重新部署。

**上传的图片打不开**

确认访问路径以 `/wp-uploads/` 开头。程序对该前缀的文件走 R2 读取并设置长缓存（`immutable`），文件名内容变则地址变。

**老版本升级后找不到「页面」菜单**

程序会在首次访问时自动创建 `pages` 表（`CREATE TABLE IF NOT EXISTS`，幂等、不影响已有数据）。若权限受限导致失败，可手动执行建表语句。

**评论提交后不显示**

默认开启「评论审核」，新评论为待审状态。后台 → 评论 → 通过后显示。可在设置里关闭审核。

## 目录与路由速查

| 路径 | 说明 |
|---|---|
| `/` | 首页 |
| `/article/{slug}` | 文章详情 |
| `/category/{slug}` | 分类列表 |
| `/tag/{slug}` | 标签列表 |
| `/archive?month=YYYY-MM` | 按月归档 |
| `/search?q=关键词` | 搜索 |
| `/about` | 关于页 |
| `/{页面slug}` | 独立页面 |
| `/wp-uploads/...` | R2 媒体文件 |
| `/install` | 安装向导（已安装后显示提示） |
| `/wp-admin/login` | 后台登录 |
| `/wp-admin` | 后台首页（仪表盘） |
| `/admin` | 旧地址，自动 302 跳转到 `/wp-admin` |
